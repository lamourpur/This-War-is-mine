# Ceux Qui Restent — notes pour Claude

Clone français de *This War of Mine*, en HTML + Canvas, JS vanilla. Pas de build, pas de dépendances : `index.html` charge des scripts classiques dans l'ordre. Le jeu doit aussi marcher en `file://`. Répondre à l'utilisateur **en français**.

## Conventions
- Chaque fichier est une IIFE ES5 `(function (C) { 'use strict'; … })(window.CQR);`. Tout vit sous `C.*` (`C.Game`, `C.Render`, `C.UI`, `C.Explore`…). Pas de modules, pas de classes, pas de syntaxe ES6+ lourde.
- Nouveau fichier JS → l'ajouter dans `index.html` au bon endroit (data avant game, game avant ui, `maps.js` après `dayevents.js`, `explore.js` après `night.js`).
- Textes du jeu en français ; noms des personnages américains (ids internes : vera, tomas, ilija, nada, goran, lena, emir, mira).
- Retours d'action **dans la scène** (`C.Render.pop(s, gains|tag, …, 'warn')`, bulles), jamais de message en bas de l'écran.
- Aide (`js/ui/help.js`) : tout `title` devient une info-bulle thémée (« Titre — détail ») ; `UI.hint(clé)` = note de première fois (`HINTS`, vues dans localStorage `cqr-hints`, option `hints`), déclenchées dans `UI.hintTick` ; manuel `UI.openHelp(page)` en onglets (`PAGES`).
- UI « dossier de survie » : polices Bebas Neue / Barlow Semi Condensed / Special Elite, papier vieilli, icônes SVG (`js/ui/icons.js`), barres de défilement thémées.

## Architecture
- `js/core/` utilitaires, audio (fichiers CC0 + synthèse de secours ; musique `assets/music` par moment : `Audio.setMood('menu'|'day'|'winter'|'evening'|'explore'|'sad')`, choisi par `musicMood` dans `main.js`, `Audio.duckMusic`), sauvegardes (localStorage + export .sav).
- `js/data/` objets (`C.ITEMS` : w = poids, v = valeur de troc), constructions, survivants, lieux de pillage, événements, plan du refuge (`shelter.js`), PNJ (`maps.js` : `C.NPCS`), plans explorables à géométrie libre (`lieux.js` : `C.MAPS`, sauf l'entrepôt dans `military.js`).
- `js/game/` état (`C.Game.st`), déplacements (`nav.js`), actions et menus contextuels (`actions.js`), besoins/moral, monde, nuit (`night.js`, `Night.resolve`), exploration jouable (`explore.js`).
- `js/render/` monde 1600×900, 4 étages (sol y 800/630/460/290). Couche statique reconstruite quand `C.Render.dirty` (`G().markDirty()`), couche dynamique chaque frame. `sketch.js` = trait crayonné, `objects.js` = meubles, `figure.js` = personnages articulés, `portrait.js` = portraits (photos `assets/portraits/<id>.jpg` + surcouches d'état), `itemart.js` = icônes d'objets, `textures.js` / `props.js` = ressources CC0 peintes dans les contours.
- `js/ui/` HUD, fenêtres (`panels.js`), fouille par glisser-déposer (`loot.js`), troc (`trade.js`), écran de nuit (`nightui.js`), carte de la ville en SVG (`citymap.js`, positions `POS`).
- Sac du pilleur en cases : `C.stackOf(id)` (piles, `C.STACK` dans `items.js`), `Explore.capacity` (10/14 cases), `Explore.slots`, `Explore.canTake(id)`, `Explore.fits(items)`.

## Exploration de nuit
`C.Explore.start(plan, onDone)` remplace temporairement les globales du plan (`C.STAIRS/WALLS/WINDOWS/SLOTS/DECOR/THEME`) et `C.Game.st` par un état d'exploration (phase `'explore'`, inventaire = sac, un seul survivant) ; tous les systèmes (nav, actions, fouille, rendu) sont réutilisés. `finish()` sauvegarde l'état du lieu dans `st.locations[id]`, restaure tout, puis `Night.resolve` lit `plan.scav.explored`. Les lieux sans plan passent par le pillage abstrait de `night.js`.
- Ajouter un lieu jouable : un plan dans `C.MAPS` (même id que dans `C.LOCATIONS`, `danger: 0`), ses PNJ dans `C.NPCS` (`need` / `trade` / `donate`, `cond: {wound, sick}` pour l'état dessiné, `afterSteal`), et le propriétaire des caches `owner` dans `C.OWNERS` (texte, perte de moral, clé de pensée dans `thoughts.js`, `later` = conséquence apprise quelques jours après, via `st.flags.later` traité à l'aube).
- Soldats (`js/data/military.js` : `C.GUARD_TYPES`, plans `entrepot` / `avant_poste`, `zones`) et combat (`js/game/combat.js`, `C.Combat`) : objets `kind: 'guard'` qui bougent (dessinés dans la couche dynamique par `C.Combat.draw`, jamais dans la couche statique), états `patrol / investigate / watch / warn / alert / search / flee / surrender / sleep`, bruit via `C.Combat.noise(f, x, rayon)`. Actions du survivant `attack`, `shoot` (gérées par `Combat.tickSurv`), `hide` (objets `kind: 'hide'`). Hostilité mémorisée dans `st.locations[id].hostile[groupe]`. Bilan moral des morts dans `Combat.consequences`.
- Rapport du matin (`Night.resolve`, `UI.openReport`) : sections `back` (« Ils sont revenus » : survivants rentrés d'une mission de jour via `st.nightNotes`, pilleur ou mercenaire rentré, remerciements `Story.thanks`, habitants revenus dans un lieu), `scav`, `home`, `people`, `market`. Une note d'exploration peut porter `sec`. PNJ : `need.reward` (après le merci), `donate.reward` + `giveLine` (au 1er don puis un sur trois).
- « Rentrer » (bandeau ou sortie) : `Explore.goHome()` = action `leave` en courant (`s.run`), caméra sur le pilleur.
- Objets donnés par un PNJ en exploration : toujours passer par `C.Explore.give(s, o, items, label)` (sac si la place, sinon baluchon à terre + fenêtre de fouille), jamais `addItems` direct.
- Modes d'exploration : `C.Explore.mode` = `'explore'` (parler, pas d'attaque dans les menus) ou `'combat'` (clic sur un soldat = `Combat.quickAttack`, arme tenue via `Combat.readyTool`). Bascule : `Combat.setMode` / touche C.
- Espacement des ennemis (`combat.js`) : `goTo` passe par `freeSpot` (jamais deux soldats sur la même destination, écart `GAP`) ; `separate()` écarte chaque image les soldats **arrêtés** (le plus proche du survivant avance d'un pas ; un soldat en marche passe sans bousculer). Au corps à corps, le second contourne de l'autre côté.
- Portes : action `peek` (`o.peeked`, voile léger sur la pièce dans `buildStatic`, `rg.peeked`). `Combat.hidden(g)` = soldat dans une région non atteinte et non regardée : pas dessiné (marque de bruit s'il bouge ou parle), pas cliquable.
- Vol (« pas vu, pas pris », comme le jeu d'origine) : ouvrir un contenant n'est pas voler, seul **prendre** l'est (`Explore.markStolen`, depuis la fenêtre de fouille ou le démontage). Le moral du groupe baisse toujours ; les habitants ne réagissent et ne gardent rancune (`ls.angry`) que si l'un d'eux a vu faire (`Explore.npcWitness(s)` : même niveau, même région, < 420 ; `E.caught[owner]`, réplique `d.caught` ou `afterSteal`). Le menu « Fouiller » dit si quelqu'un regarde.
- Jugement du groupe (`Mood.judge(sins, {merc, mercFemale, except})` dans `mood.js`) : vols (`steal`), braquages (`rob`), meurtres (`kill`, `kill_surrender`) de la nuit sont collectés dans `E.sins` (pas de `moralAll` direct) ; chaque survivant réagit selon `Mood.stance` (cynique/combattant/faim/pénurie → approuve, empathique/soignant/deuil → choqué, un peu de hasard stable ; mercenaire = plus facile à accepter mais on l'a payé) ; la pire faute compte en entier, les autres à 35 %, plafond −18. Lignes dans la section `people` du rapport, pensées, dispute si le groupe est divisé ; bulles au début de la journée (`Mood.replayReactions`, `st.flags.reactions`).
- Tuer marque (`Combat.consequences` → `Mood.remorse(s, coup, jours, sorte, rang)`) : coup immédiat lourd pour le tueur (défense 26, sommeil 34, sans menace 38, reddition 45 ; ×0,35 cynique, ×1,25 empathique, ×0,8 combattant, +30 % par mort supplémentaire), puis `s.remorse` = jours de remords (état « Rongé(e) par le remords ») qui font perdre 3 à 6 de moral chaque matin (`Mood.remorseDawn`, réveils en sursaut dans le rapport) ; le groupe juge via `Mood.judge` (plafond −38 pour un meurtre, fautes suivantes à 60 %). Le réconfort et le recueillement aident. Le mercenaire qui tue n'a pas de remords, seulement le jugement du groupe.
- Braquage : `Explore.canRob(o)` / `Explore.rob(s, o)` (action `npc` avec `what: 'rob'`) ; la moitié du stock du PNJ ou `d.rob`, `E.stolen[ownerHere()]`, pensée `robbed`.
- Arme en main : `C.Combat.weapon()` (choix `Explore.weapon` validé, sinon la meilleure), `setWeapon`, `cycleWeapon` (touche A), `weapons()` ; `Combat.plan` / `menu` / `readyTool` l'utilisent.
- Plan de nuit (`nightui.js`) : deux écrans empilés — « La nuit tombe » (rôles `bed` / `sleep` (par terre) / `guard` / `scav`, mercenaire, bilan ; bouton « Choisir le lieu → ») puis « Où aller cette nuit ? » (`openLocation` : carte `CityMap` + photo et notes du lieu ; « Préparer le sac → » ouvre le sac, « Retour » revient) ; plus d'attitude ni de priorité (réservées au pillage abstrait du bot) ; `depart()` ferme toutes les fenêtres ; `plan.explicitBeds` ; sac de l'explorateur `plan.scav.bag` (objets → cases), rempli sur l'écran `UI.openPack(plan, s, onGo, onClose)` (`js/ui/pack.js`, glisser-déposer, `UI.locationIntel(st, id)` = ce que l'on sait du lieu) ; `equip`/`ammo` déduits par `UI.syncBag` (le bot n'utilise que `equip`/`ammo`). Fondus : `Main.fadeThrough({icon,title,text}, mid)` et `Main.dawnFade(st, cb)` ; `Main.noFade` les coupe (bot).
- Oisiveté : `Surv.update` compte `s.idleT` (journée, sans action) ; à 15 min, `Actions.autoIdle(s)`, dans l'ordre : dormir (fatigue ≥ 75) ; **le manque** (fumeur sans cigarette depuis la veille → `smoke`, accro au café → `coffee`, seulement s'ils en ont en réserve) ; moral < 45 ou fatigue ≥ 45 → fauteuil (`read` si livre et moral < 60, sinon `rest`) ; **l'envie**, tirage pondéré (lecture, `music` à la radio, `guitar` si quelqu'un écoute, `talk` / réconfort avec un autre survivant inactif, plus souvent pour lecteur / empathique) ; sinon quelques pas ou action `idle` (`floor` / `lean`). Bulle courte au début (`IDLE_SAY`). Jamais d'avertissement à l'écran (`can()` teste avant). Actions auto : `p.auto` (pas de clic sonore).
- Armes à feu : `K.GUNS` dans `combat.js` (`pistolet`, `fusil`, `fusil_pompe`, `fusil_assaut` ; `loud` = multiplicateur de bruit). `casque` (`armor`) réduit les dégâts reçus (×0,82). Événements de jour dans `dayevents.js` (libellés de choix possibles en fonction ; `st.flags.catUntil` bloque les rats).
- Faim : `C.Surv.feedHunger(s, faim, heures)` (plafond 100, compteur `s.starving`) ; la mort de faim n'arrive qu'à l'aube (`checkDeath(s, true)`) après `Surv.STARVE_H` heures à 100.
- Temps en exploration : `gm` = minutes de jeu (1,6 par seconde), `rs` = secondes réelles × vitesse (IA, cadence de tir).
- **Plans à géométrie libre** (`layout: true` dans `C.MAPS`, ex. `entrepot` dans `military.js`) : le plan apporte son monde (`world` : W, H, `view` = largeur cadrée ; la caméra défile), ses niveaux (`floors` : y, ceil, x0, x1, `ground`/`catwalk`/`out`/`noSlab`, `segs`, `support`, `hang`), `start`, `rooms` (murs du fond, poteaux, charpente, rayonnages, suspensions, enseigne), `shells` (bâtiments : murs avec `gaps`, toit `saw`/`flat`/`gable`), `stairs` typés (`metal`, `ladder`, `hole`, `link` = passage invisible entre deux niveaux de même hauteur), `fences`, `things` (chariot élévateur, conteneur, camion), `lights` (`brasero`, `lamp`, `searchlight`), `backdrop` (plans de parallaxe). `Explore.start` échange `C.WORLD`, `C.FLOORS`, `C.LAYOUT` et `C.NAV_START`, puis `Render.worldChanged()`. Rendu : `js/render/layout.js` (`C.Layout`) ; l'architecture est mise en cache (`Render.arch`), seuls objets et brouillard sont redessinés. Bords de niveau : toujours `C.Nav.x0/x1(f)`, `minX/maxX(f)`, `clampX(f, x)` (jamais `C.WORLD.walkMin/Max`). Pose `climb` sur une échelle ou un trou. Habillage (`layout.js`) : pièces (`paper`, `wainscot`, `frames`, `bulbs`, `tubes`, `vault`, `boards`, `shelves`, `bell`, `crucifix`, `clock`, `posters`, `signs`, `breach` = mur crevé, `attic`, `frame` = ossature de béton), toits `tiles` (percé : `hole`), `ruin`, `gable` (`cross`), `tower` (clocher), `flag`, `sign`, `chimneys` ; fenêtres `shop`, `stained`, `arch`, `round`, `strip` ; `things` (`car`, `bus`, `tank`, `crater`, `tree`, `crane`, `hedgehog`, `sandwall`, `tent`, `wall`, `lift`, `oven`, `goal`, `swing`, `pumps`, `kiosk`, `bench`, `scaffold`, `barricade` ; `back: true` = derrière les bâtiments, `dy`, `s`) ; escaliers `debris` (pente de gravats) ; niveaux `broken`, `scaffold`, `support` (poteaux), `carpet` ; arrière-plans `houses`, `towers`, `steeples`, `trees` ; lumière `candle`. Zone `exposed` : `ceil` possible. Ambiance par lieu : `mood` (`dark`, `tint` en lumière douce, `moon` = clair de lune par les fenêtres), table `MOODS` dans `lieux.js`. Pièces : aussi `shaft` (cage d'ascenseur) ; `things` : aussi `train`, `billboard`, `cabin`. Caches : `gondole`, `caisse_mag`, `linceul` (corps sous un drap), `baluchon` (tissu à carreaux noué, texture `cloth` = `gingham_check` ; `hessian` = toile de jute). Écrits : objets `kind: 'note'` (`title`, `text`, `wall`/`dy`, `book`, `journal`, `opens` = ce qu'on y apprend, `say`, `bio`), action `readnote` ; ajoutés par la table `EXTRA` en fin de `lieux.js`. PNJ : `need.opens` (ouvre une porte, déverrouille un coffre) ; otages génériques : `rescued` + `captor` (groupe du geôlier), `freedNote`, `abandonNote`, `rescueJournal`, `abandonJournal`. Tireur : `Combat.unseen(g)` (invisible sauf si l'on est à son étage ; il se défend à bout portant), reflet de lunette dans `drawCursor`. Nouvelles variantes : caches `palettes`, `conteneur`, `casiers`, `rayonnage`, `bureau_metal`, `caisse_mil`, `bac`, `boite_outils`… ; cachettes `palettes`, `voiture`, `sacs`, `bidons` ; sortie `portail`.
- **Tous les lieux sont jouables** (pas de pillage automatique pour le joueur ; `scavenge()` de `night.js` ne sert plus qu'au bot). Plans : tous en géométrie libre, dans `lieux.js` (l'entrepôt dans `military.js`). Personnages : `maps.js` (lieux civils), `military.js` (soldats), `maps_ville.js` (bandits, pilleurs, tireur), `maps_extra.js` (type `squatteur` ; PNJ `noRob` = jamais braqué). Habitants armés tués ou épargnés : mémorisés dans `st.locations[id].gone[key]` (`Combat.gone`) ; un garde marqué `'gone'` sans cette mémoire revient (réparation des vieilles sauvegardes). Garder les `key` des objets quand on redessine un plan (état mémorisé dans `st.locations[id].map`).
- Tolérance : types `tolerant` (pilleur, squatteur) : traverser leur zone ne fait qu'avertir ; ils n'attaquent que si l'on s'y attarde (arrêté ou en train de fouiller), qu'on les frôle ou qu'on les vole. Textes du carnet selon `Combat.catOf(g)` (`mil` / `bandit` / `civ` / `sniper`), `nounOf`, `whoOf` (« Ray », « un soldat ») ; corps : `label` « Corps de Ray ».
- Types armés supplémentaires (`maps_ville.js`) : `bandit` (couteau, `mdmg`), `bandit_arme` (pistolet), `pilleur` (neutre, zone « chasse gardée », `name` propre sur l'objet), `tireur` (`sniper`/`fixed`/`unseen` : ne voit que les zones `exposed` du plan, ne bouge pas, invisible). Contenants gardés : `owner: 'bande'` (comme l'armée) ou `'pilleur'`.

## Événements généraux (comme le jeu d'origine)
- `World.noRaids(st)` = accalmie hivernale (`winterCalm`, 3 jours en plein froid, `st.calmStart`, décalée hors de la vague de criminalité) ou « Curb on Crime » (`crimeCurb`, 2 jours après les 6 jours de criminalité) : `Night.raidChance` = 0. Signalés seulement à la radio (`World.news`, une info tirée parmi celles du moment).
- Zones bouclées : `st.flags.closures = [{id, from, until}]`, `World.closed(st, id)`, `World.dawnClosures` (annonce, réouverture, nouvelle zone dès le jour 6) ; la carte grise le lieu (« zone de combats ») et le refuse ; le bot les évite. Pénuries annoncées 3 jours avant (`Market` : `m.upcoming`, `Market.soonText`) ; Casques bleus à ≤ 7 jours du cessez-le-feu.
- Épilogue (`epilogue` dans `panels.js`) : par survivant `s.kills`, `s.execs` (homme rendu), `s.thefts`, `s.robs`, `s.helps`, `s.spares` (comptés à la fin de chaque exploration dans `Explore.finish`, `Mood.remorse` pour les meurtres) + `st.stats.helped/refused/stole`.

## Événements de lieux (comme le jeu d'origine)
- Objets conditionnels d'un plan : champ `only` (`'grisha_dead'`, `'shelled'`, `'team'`), testé par `Explore.onlyOK(d, ls)` au lancement ; jamais marqués « disparus » tant qu'ils n'ont pas paru. `need.alts` = paiements alternatifs (`Explore.needPay`) ; `need.openNote` ; `donate.alts` + `shelledThanks` / `shelledMoral`.
- Squat : Grisha (`C.NPCS.grisha`, mange n'importe quoi → ouvre `cachette_grisha`, bijoux et gnôle) ; entrevu puis non nourri, il est mort à la visite suivante (`ls.npc.grisha.dead`), remplacé par `squat_inconnu` + `corps_grisha`.
- Hôtel : `porte_ravisseurs` (f3, x 1350) scelle, avec `porte_suite`, la suite du fond : 4 voyous (`group: 'voyous'`) et `gabriel` (otage, `captor: 'voyous'`) ; la suite du lieutenant se traverse donc par leur repaire.
- Hôpital : `ls.shelled` dès le jour 9 → 3 gravats bloquants et `fournitures` (sous-sol, `only: 'shelled'`) ; Ruth réclame les fournitures (`d.shelled`) et remercie fort si on les lui rapporte.
- Chantier : `ls.team` (70 %, tiré à la première visite) → nid de tireurs derrière le coffrage effondré (dalle du haut) : `tireur_elite` (`fusil_lunette` en butin) et son guetteur ; l'arme `fusil_lunette` (`K.GUNS`, portée 900, précision 0,94).

## Refuge agrandi
- Abri souterrain (`js/game/cellar.js`, `C.Cellar`) : 5e étage du refuge `C.FLOORS[4]` (`cellar: true`, `hidden` tant qu'il n'est pas ouvert ; x0/x1 propres). `st.flags.cave` = `'found'` (trappe `kind: 'trapdoor'` posée à l'aube du jour `Cellar.DAY` par `Cellar.dawn`, appelée dans `World.dawnStations`) puis `'open'` (action `pry` → `Cellar.open`). `Cellar.apply(st)` (nouvelle partie, chargement, ouverture) recompose `C.STAIRS/SLOTS/WALLS/DECOR` et passe `C.WORLD.H` à 1060 (`Render.worldChanged`). Les étages `hidden` sont ignorés par `Nav.computeRegions` et `Render.floorAt` ; le dessin est `drawCellar` dans `renderer.js` (les boucles de `drawHouse` sautent `fl.cellar`). Morts au refuge : `Surv.kill` (hors exploration, sauf `parti`/`pillage`) pose un objet `kind: 'corpse'` (`since` = jour) ; à l'aube il coûte du moral (et rend malade après 3 jours) ; action `bury` (pelle = plus vite) → objet `memorial` (bougie dans `drawLights`), action `mourn` une fois par jour. Lecture à voix haute : action `talk` avec `mode: 'read'` (un livre, non consommé, une fois par jour, `b.readToDay`). Usure des outils : `C.WEAR_MAX` (`items.js`), `Game.wear(id, n, s)` (casse et retire l'objet), `Game.wearLeft(id)`, état dans `st.flags.wear` (partagé avec l'exploration) ; appelé par `unlock`, `clear`, `cut`, `dismantle`, `pry`, `bury` et chaque coup de mêlée ; barre `.inv-wear` dans la réserve. Atelier d'armurier : station `gunbench` (établi niv. 2), recettes `C.STATION_RECIPES.gunbench` via l'action `cook` (`maintain` = remet toute l'usure à zéro ; `batch` = fabrication en lots, écran `UI.openBatch(s, o, r)` dans `panels.js`, `p.n` multiplie coût, durée et produit ; munitions, silencieux, armes à assembler) ; objets `pieces_armes` (caches militaires et bandits, Franko jour 10) et `pistolet_silencieux` (`K.GUNS`, `loud` 0,22). Contenants vides du refuge (`kind: 'cache'` sans `owner`, hors exploration) : « Démonter » (action `dismantle` avec `p.scrap`, table `SCRAP` par variante dans `actions.js`) rend du bois et libère la place. En exploration d'un plan classique, `Explore.start` ne garde que les 4 premiers étages et H = 900.

## Mercenaires
- `js/game/merc.js` (`C.Merc`, après `market.js`) : à partir du jour `Merc.DAY` (10), Milo propose chaque matin un mercenaire (`Merc.dawn`, appelé dans `Night.dawn` après `Market.dawn` ; état `st.merc = { offer, hired, dead }`, `st.flags.merc`). Profils `ARCH` (`ombre`, `colosse`, `veteran`, `fouineur` : traits du jeu ; pas d'équipement propre, on compose son sac). Prix payé d'avance (`hire` / `dismiss` rend), toujours une ressource en pénurie (`Market.wanted`) ou un objet précieux, + objets courants, croissant avec les jours ; un mercenaire rentré vivant peut revenir moins cher (`returning`).
- Nuit (`nightui.js`) : carte du mercenaire (`mercCard`) ; engagé, `plan.merc` = l'offre et `scavenger()` renvoie `Merc.body(o)` (survivant temporaire `merc: true`, `id: 'merc'`). Aucun survivant ne sort. `Explore.start` l'utilise comme pilleur (`E.merc`) ; au retour `Night.resolve` ajoute tout le sac (`Merc.back`). Mort : pas de `Surv.kill`, `Merc.lost`. Vols et meurtres : jugés par `Mood.judge` avec `merc` (réactions propres au mercenaire). Portrait : photo `assets/portraits/merc/h1..h5|f1..f5.jpg` (`Merc.photoOf(o)` → clé `m_<id>` de `portrait.js`, choisie d'après le nom). Fiche d'expédition : `exp.merc` remplace le survivant ; bandeau/info-bulle : `Merc.def(s)`, pas de dossier.

## Survivants

## Histoires
`js/data/stories.js` : les étapes sont des visiteurs (`C.VISITORS`). Le début porte `once: '<id>'` et `canAppear`, les étapes suivantes `story: true` (jamais tirées au hasard). `C.Story.next(st, step, jours)` programme la suite, `C.Story.news(st, jours, texte, moral, clé)` annonce une nouvelle au matin, `C.Story.thanks(st, jours, texte, objets, moral)` ; histoires : Emma, le déserteur Danny, Sara (femme enceinte : `sara_1..3`, absence `accouchement`, le bébé porte le prénom de qui a aidé) et le sergent Hollis (`soldat_1..3` : mort au refuge = objet `corpse` à enterrer ; sauvé = `st.flags.guardedUntil`, risque de pillage ×0,3 dans `Night.raidChance`) = quelqu'un qu'on a aidé revient remercier avec un cadeau (toute aide à la porte doit rapporter quelque chose, tout de suite ou ainsi), et `onMissed(st)` se déclenche si personne n'ouvre. État dans `st.story` / `st.storyQueue`.

## Visiteurs
- Troc (`js/ui/trade.js`, `TradeUI.open(s, stock, onDone, {name, likes, bag, face, faceLine})`) : glisser-déposer à quatre casiers (vos objets, « Vous donnez », « Vous recevez », ses objets ; zones `mine`/`give`/`take`/`stock`, `dest()` décide où va une pile, la balance au centre accepte aussi le dépôt) ; prix `buyP` (ce qu'il paie, × `likes`) et `sellP` ; `bag` = depuis le sac en exploration (cases vérifiées).
- Marché (`js/game/market.js`, `C.Market`, chargé après `world.js`) : pénuries `C.SHORTAGES` (`items` = multiplicateurs), état `st.market` ; `Market.mult(id)` est appliqué dans `Trade.scarcity` (tous les prix de troc) ; `Market.dawn` écrit la section `market` du rapport. Franko = visiteur `marchand` (`scheduled: true`, jamais tiré au hasard), programmé par `World.planVisitor` via `Market.frankoDue` ; stock par paliers de jours dans `Market.traderStock`.
- Planification (`World.planVisitor`) : à partir du jour 2, histoire due > Franko > visiteur au hasard (85 %), puis parfois un second (`st.visitorQueue`) ; attente 240 min ; `weight` peut être une fonction ; `onMissed(st, data)`. Cadeaux différés : `st.flags.gifts` (`{day, items}`) ajoutés à l'aube.
`js/data/visitor_faces.js` (`C.VISITOR_PEOPLE[id]`) : `name`, `face` (fiche de portrait, enregistrée sous `v_<id>` dans `portrait.js`), `state` (blessure, maladie… sur le portrait), `figs` (silhouettes dessinées devant la porte par `drawVisitors` dans `renderer.js`), `hurt`, `armed`. Une photo `assets/portraits/pnj/<id>.jpg` remplace le dessin ; sinon le dessin passe au filtre fusain. Le réfugié utilise le portrait et la silhouette du survivant qu'il deviendra. `UI.visitorFace(v)` / `UI.visitorPortrait(v, w, h)`.

## Pièges connus
- `file://` : canvas « tainted » → `ItemArt.buildingUrl` désactive textures/props ; audio en HTMLAudio au lieu de Web Audio.
- Toute modif de décor statique doit appeler `markDirty()` sinon rien ne se redessine.
- Caméra (`renderer.js`) : `R.base` = cadrage d'ensemble, `R.cam = {z, cx, cy, follow}`, `R.applyCam()` recalcule `R.scale/ox/oy` à chaque image (`camStep`) ; `zoomAt`, `panBy`, `camFollow(s, z)`, `camReset`. Exploration : `camFollow(s, 1.6)` à l'entrée, `camReset` à la sortie. Plan large (`C.WORLD.view`) : suivi du pilleur à tout zoom (`camStep`), recul jusqu'à `R.zMin()` (tout le lieu), défilement continu dans `camScroll` (`main.js`) : souris au bord de l'écran (`EDGE`), flèches / Q-D maintenues (`Main.panKeys`), plus clic droit glissé (`panBy`), F = recentrer ; un ordre de marche relance le suivi ; pilleur hors champ = repère cliquable au bord (`offscreenMarker`, `R.offMarker`). `staticRes()` redessine le décor plus finement après un zoom. Toujours passer par `toWorld`/`toScreen`.
- Performances : reconstruire la couche statique coûte cher (≈150 ms en 4K). En exploration, `addItems` / `removeItems` n'appellent pas `markDirty` (`Game.invDirty`) ; au refuge, seulement si l'aspect des étagères change (`ObjDraw.stockLook`). Murs, toit, rue et objets détourés du refuge sont rendus une fois dans `R.arch` (clé : taille, thème, abri ouvert, `R.archGen` bumpé par `worldChanged`, décor masqué par les meubles) ; un redessin ne refait que les objets et le brouillard. Le décor est plafonné à `STATIC_MAX_W` px (`R.sScale`, qui peut être plus petit que `R.scale`). Ne jamais appeler `markDirty` à chaque frame ou à chaque tir.
- Silhouettes de surbrillance : mettre `SK.noStain = true` pour ne pas y inclure taches et ombres.
